1. UNE SEULE FOIS : PROTEGER LA CLE
-----------------------------------
Windows refuse une cle .pem lisible par tout le monde
(erreur "UNPROTECTED PRIVATE KEY FILE"). Dans PowerShell :

icacls "C:\Users\Ashraf\Downloads\das2026.pem" /inheritance:r /grant:r "$env:USERNAME:(R)"


2. OUVRIR LE TUNNEL
-------------------
Dans PowerShell. La fenetre reste ouverte tant que le tunnel sert :
ne la fermez pas, et n'attendez pas de message, -N ne renvoie rien.

ssh -i "C:\Users\Ashraf\Downloads\das2026.pem" -N -o ServerAliveInterval=60 -L 8080:localhost:8080 ubuntu@50.19.46.247

Puis, dans le navigateur :  http://localhost:8080

Fermer le tunnel : Ctrl+C dans cette fenetre PowerShell.


3. SI LE PORT 8080 EST DEJA PRIS SUR LE POSTE
---------------------------------------------
Message "bind: Address already in use". Utilisez un autre port local :

ssh -i "C:\Users\Ashraf\Downloads\das2026.pem" -N -o ServerAliveInterval=60 -L 8081:localhost:8080 ubuntu@50.19.46.247

Puis :  http://localhost:8081

Verifier ce qui occupe le port 8080 :
netstat -ano | findstr ":8080"


4. SI VOUS PASSEZ PAR EC2 INSTANCE CONNECT
------------------------------------------
Gardez la meme option -L 8080:localhost:8080 dans la commande proposee
par la console AWS : c'est elle qui ramene Jenkins sur votre poste.
